Look for the following reserved keywords in the code and expand as follow
Every compiled line should start with "#!c "

USERNAME[LOWER]: Repeat the line of code for each user in the users.txt file, replacing USERNAME with the respective usernames. If LOWER is appended, convert all letters to lowercase before inserting username. Meant to house active player usernames
ADMINUSERNAME[LOWER]: Same as above, but from the admin.txt file. Meant to house admin usernames
TASKID | TASKTITLE | TASKDESCRIPTION | NEWLINE: Repeat the line of code for each task in the tasks.txt file, filling in each part of the task accordingly. Replace any NEWLINE with a newline character
NUMBEROFTASKS: Replace this with the total number of tasks

Do not remove any "# [Generated From Compiler]" lines, as these are used by the compiler
> If you want to remove a line, remove both the line and its generated comment
